# Framix 概览

## 项目定位

Framix 是用于移动应用性能测试和视频视觉分析的 CLI 工具。

它通过录屏、视频拆帧、视觉识别、模型分析和结构化报告，帮助测试人员和开发人员判断应用在真实用户视角下的性能表现。

## 核心价值

Framix 偏向非侵入式分析，通过用户可见画面判断：

- 启动是否慢
- 页面切换是否卡顿
- 功能执行是否超时
- 视频帧变化是否符合预期
- 关键操作是否存在性能瓶颈

## 主要分析对象

- APP 启动耗时
- 页面切换耗时
- 功能执行耗时
- 视频帧变化
- 关键帧区间
- 多视频对比
- 模型训练样本
- 结构化性能报告

## 典型产物

- HTML 报告
- JSON 数据
- 视频帧图片
- 关键帧识别结果
- 统计曲线
- 模型训练数据
- 合并后的分析报告

## 使用建议

- 快速查看帧变化时，优先使用 `--speed`。
- 需要准确耗时或时间戳时，优先使用 `--basic`。
- 需要模型辅助识别时，使用 `--keras` 或 `--infer`。
- 命令示例除 `--apply` 外必须包含 `--debug`，便于输出可见日志。
