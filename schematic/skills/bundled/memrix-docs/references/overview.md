# Memrix 概览

## 项目定位

Memrix 是用于移动应用性能测试和资源分析的 CLI 工具。

它通过 ADB、Perfetto、内存采样、I/O 采样、帧率分析和结构化报告，帮助测试人员判断应用是否存在内存异常、性能瓶颈、卡顿和资源使用不稳定等问题。

## 核心价值

Memrix 主要解决以下问题：

- 内存使用是否持续上涨
- 是否存在疑似内存泄漏
- I/O 行为是否异常
- 页面或交互是否存在卡顿
- 帧率是否稳定
- 测试结果是否可以自动报告化
- 是否满足准出标准

## 主要分析对象

- Android 应用包名
- ADB 设备
- Perfetto trace 文件
- 内存采样数据
- I/O 行为数据
- 帧率和 Jank 指标
- 测试输出目录
- HTML 报告

## 典型产物

- HTML 性能报告
- 内存趋势图
- I/O 行为图表
- 帧率稳定性分析
- 流畅度评分
- 多维度准出判断
- 测试日志和中间数据

## 使用建议

- 测试应用内存和 I/O 时，优先使用 `--storm`。
- 分析流畅度和掉帧时，优先使用 `--sleek`。
- 生成报告时，使用 `--forge` 或追加 `--atlas`。
- 按标准评分时，追加 `--align`。
- 连接多台设备时，必须使用 `--imply` 指定设备。
- Memrix 命令示例除 `--apply` 外必须包含 `--debug`，便于输出可见日志。
