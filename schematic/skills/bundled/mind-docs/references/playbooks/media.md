# Media 场景

## What

`Media` 处理的是文件级多媒体任务，不负责解释用户体感或性能阶段。

典型任务：

- 视频裁剪。
- 抽帧。
- 转码。
- 拼接。
- 音轨处理。
- 录屏与镜像。
- 音频播放。

## When To Use

- 你已经有视频或音频文件。
- 你要输出处理后的文件、探测信息或帧目录。
- 你要开始一段本地录屏，或只打开镜像会话观察设备画面。
- 你要播放一段本地音频做联调或验收。

## When Not To Use

- 你要分析“哪一段画面最慢”，优先看 [Framix 场景](framix.md)。
- 你要解释内存或 FPS 趋势，优先看 [Memrix 场景](memrix.md)。

## Core Rules

- 给出输入文件名或目录。
- 给出精确时间范围、帧数或抽帧策略。
- 给出输出要求：格式、静音、缩放、拼接顺序。
- 给出最终产出：输出路径、探测信息、关键帧摘要。
- 使用策略要与当前工具集对齐：单帧截图、批量抽帧、关键帧抽取、时间裁剪、探测信息、音轨处理、录屏/镜像、音频播放是分开的能力，不要用一个泛化示例试图覆盖所有动作。
- 示例应保留高层目标、时间范围、输出要求和摘要要求，不要下沉成 ffmpeg 参数清单。

## Good Examples

```bash
mind --chat "从 demo.mp4 裁剪 00:00:05-00:00:12，提取 6 张关键帧，返回输出路径和摘要。"
```

```bash
mind --chat "将 a.mp4、b.mp4、c.mp4 按顺序拼接成一个 mp4，统一缩放到 1280x720，静音处理，并返回输出路径与探测摘要。"
```

补充示例：

```bash
mind --chat "从 demo.mp4 的第 5 秒截一张静态图，再补一份探测摘要；返回截图路径、时长和主要编码信息。"
```

```bash
mind --chat "从 demo.mp4 的 00:00:05 到 00:00:12 做时间裁剪，并额外抽取 6 张关键帧；返回输出文件路径、关键帧目录和简要摘要。"
```

```bash
mind --chat "把 a.mp4、b.mp4、c.mp4 顺序拼接成一个文件，统一输出为 mp4；完成后返回输出路径，并补一份探测摘要确认容器和时长。"
```

```bash
mind --plan "开始一段设备录屏，覆盖首页进入详情页的完整操作；结束后返回录屏文件路径，并基于这段视频补一份关键帧摘要。"
```

```bash
mind --chat "只打开设备画面镜像，观察当前页面是否稳定显示；不录屏，只返回镜像会话是否建立成功。"
```

```bash
mind --chat "播放本地提示音文件，音量设为中等；只返回播放是否成功，不做额外媒体处理。"
```

## Bad Examples

```bash
mind --chat "看一下这个视频。"
```

问题：

- 没写输入目标。
- 没写动作类型。
- 没写产出形态。

```bash
mind --chat "随便录一下屏，再帮我处理成合适的东西。"
```

问题：

- 没写录哪条路径。
- 没写录完之后要抽帧、裁剪、分析还是只保存文件。
- 没写最终要返回什么产物。

## Checklist

- 是否写明输入文件。
- 是否写明时间范围、帧策略或输出格式。
- 是否写明最终要返回的路径和摘要。
- 示例是否保持为人能直接理解的处理目标，而不是 ffmpeg 参数对象。
- 如果涉及录屏或镜像，是否写清是“只观察”“保存录屏”还是“录完继续分析”。

## Failure Handling

- 输入文件不存在时，明确返回缺失路径。
- 时间范围非法时，返回可修正的时间区间建议。
