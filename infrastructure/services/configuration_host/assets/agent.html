连接指引

三个步骤，从本机到 Web。

  1. 启动客户端监听让这台设备保持在线
  2. 复制设备密钥密钥会在上方自动显示
  3. 打开 Mind Web粘贴密钥，开始远程对话
在 Mind 客户端输入
/listen start

也可以从终端运行 mind agent listen。连接成功后，API Key 会自动显示。

如何让远程任务自动开始？

在客户端输入 /mailbox 并开启 Auto-run。否则任务会等待你在客户端选择 Run。执行权限和审批沿用客户端设置。
